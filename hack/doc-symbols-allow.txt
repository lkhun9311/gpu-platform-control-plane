# Names the published docs spell out that this repository deliberately does not contain.
#
# Format: TOKEN<TAB>reason. The reason is mandatory and is enforced by hack/check-doc-symbols.sh, because an
# allowlist whose entries carry no reason is where a failing check goes to be taught to pass.
#
# A name belongs here only when the document is ALREADY honest about it -- it says the thing is designed,
# deferred, or absent. A name that the document asserts as working belongs in the document's correction, not
# in this file.
#
# Known limitation: an entry here is global, not scoped to the line that earned it. Once a name is listed,
# a LATER document could assert it as working and this check would stay silent. The check buys the half that
# is mechanical -- a name nothing in the repository spells -- and buys nothing about whether a name that
# exists is described correctly. Scoping entries per file would close the first gap and is not built.
#
# The scan covers the tracked specs under docs/superpowers/specs/ since 2026-09-27. The two entries that
# widening added are at the end, under their own heading, so a reader can see what the wider scope cost.
